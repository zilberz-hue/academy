# Tizon Academy

קורסי טיזון — רפואה סינית ונטורופתיה.

תשעה קורסי רפואה סינית ונטורופתיה של ד״ר צחי זילבר, תחת מערכת עיצוב אחת.
אתר סטטי — HTML, CSS ו-JS רגילים. אין framework ואין שלב קומפילציה בדיפלוי.

```
.
├── index.html          דף הבית — נוצר מ-courses.json
├── courses.json        המטא-דאטה של הקורסים (כותרת, תיאור, מספר שיעורים, קבוצה)
├── courses/            תשעת הקורסים — זה המקור, כאן עורכים תוכן
│   ├── tongue.html
│   ├── orthopedics.html
│   ├── gynecology.html
│   ├── digestive.html
│   ├── winter.html
│   ├── skin.html
│   ├── cosmetics.html
│   ├── creams.html
│   └── ai.html
├── assets/             מערכת העיצוב — משותפת לכל הקורסים
│   ├── tizon.css       טוקנים + נרמול + hero + תוכן הקורס + שכבת הדפסה
│   ├── toc.js          בניית בלוק "תוכן הקורס" מהתוכן עצמו
│   └── logo.png        הלוגו הרשמי
├── pdf/                גרסאות PDF — נוצרות ב-npm run pdf ומקומיטות
├── scripts/
│   ├── build-index.py       courses.json → index.html
│   ├── build-standalone.py  courses/ → dist/standalone/ (קובץ עצמאי לכל קורס)
│   └── build-pdf.js         dist/standalone/ → pdf/
└── netlify.toml
```

## איך זה בנוי

כל קורס הוא קובץ HTML עצמאי עם התוכן והלוגיקה שלו. מה שמשותף לכולם יושב ב-`assets/`:

- **`assets/tizon.css`** — הפלטה, הטיפוגרפיה, ה-hero, בלוק תוכן הקורס ושכבת ההדפסה.
  שינוי כאן משנה את כל תשעת הקורסים.
- **`<style id="tizon-course">`** בתוך כל קורס — מה שייחודי לו בלבד: מיפוי משתני הצבע
  הישנים שלו לטוקנים המשותפים, והתאמות נקודתיות.

החלוקה הזו היא העיקר: **עיצוב משותף → `assets/tizon.css`. חריג של קורס אחד → הבלוק שבתוכו.**

## פקודות

```bash
npm install             # playwright + גופני המותג (לבניית PDF)

npm run index           # לרענן את דף הבית אחרי שינוי ב-courses.json
npm run standalone      # לייצר קובץ עצמאי לכל קורס → dist/standalone/
npm run pdf             # לייצר מחדש את כל ה-PDF → pdf/
npm run check           # שער האיכות — מריץ את כל הקורסים בדפדפן
npm run build           # index + pdf + check
```

בדרך כלל לא צריך להריץ כלום מזה — ה-GitHub Action עושה את הכול בכל push.

`dist/` לא נכנס ל-git. `pdf/` כן — כדי שהאתר יגיש אותם בלי שלב בנייה.

## אוטומציה

כל דחיפה ל-`main` שנוגעת ב-`courses/`, `assets/`, `courses.json` או `scripts/` מפעילה
את `.github/workflows/build.yml`, שעושה את הרצף הזה:

1. `build-index.py` — מרענן את `index.html` מ-`courses.json`
2. `build-standalone.py --fonts` — קובץ עצמאי לכל קורס, גופני המותג מוטמעים
3. `build-pdf.js` — מרנדר מחדש את כל ה-PDF
4. **`check.js` — שער איכות.** נופל אם משהו באמת שבור
5. מקמט חזרה את `index.html` ואת `pdf/` עם `[skip ci]`

Netlify מחובר לאותו branch ומעלה מהקומיט הזה. כלומר: **דוחפים שינוי תוכן, והאתר
מתעדכן לבד — כולל ה-PDF.** אין צורך להריץ build ידנית לפני push.

### מה השער בודק

לכל אחד מעשרת הקורסים, בדפדפן אמיתי:

- אפס שגיאות JavaScript
- אפס קבצים מקומיים חסרים (נתיב שבור לנכס)
- מערכת העיצוב חיה — רקע קלף, גוף ב-Assistant
- **בדיוק אינדקס אחד גלוי** — זה מה שתופס את הצגת תוכן הקורס פעמיים
- hero קיים ונושא את הלוגו
- מספר היחידות בדף תואם ל-`courses.json`
- אין גלילה אופקית
- כל קישור ב-`index.html` מצביע על קובץ שקיים

השער נבדק מול שבר אמיתי: נתיב CSS שגוי, שגיאת JS ואינדקס כפול — כל השלושה נתפסו
והבנייה נפלה.

להרצה מקומית: `npm run check`

## להוסיף קורס

1. להוסיף `courses/<slug>.html`. בתוך ה-`<head>`:

   ```html
   <link rel="stylesheet" href="../assets/tizon.css">
   <style id="tizon-course">
     /* רק מה שייחודי לקורס הזה */
   </style>
   ```

2. לסמן את כותרת הפתיחה ב-`class="tz-hero"` — היא מקבלת את הרקע הירוק,
   קו הברונזה, ובהדפסה הופכת לעמוד שער מלא.

3. אם רוצים את בלוק "תוכן הקורס", לפני `</body>`:

   ```html
   <script>window.__TZ_TOC__ = {
     mountAfter: 'header.tz-hero',   // אחרי איזה אלמנט להציב אותו
     item:       'section.lesson',   // מה נחשב שיעור
     title_sel:  'h2',               // מאיפה לקחת את שם השיעור
     sub:        'h3',               // תת-הנושאים שיוצגו כתיאור
     nav:        '#tocList > *',     // אופציונלי — פריטי הניווט המקבילים
     note:       '{n} שיעורים',
     printOnly:  false               // true אם לקורס כבר יש אינדקס משלו
   };</script>
   <script src="../assets/toc.js" defer></script>
   ```

   `printOnly: true` מסתיר את הבלוק על המסך ומשאיר אותו רק בהדפסה — זה מה שמונע
   הצגה כפולה בקורסים שכבר יש להם סיידבר או שורת טאבים.

4. להוסיף ערך ל-`courses.json` ולהריץ `npm run index`.

## הדפסה

לכל קורס יש כפתור "הדפסה / PDF" בפינה השמאלית העליונה. בהדפסה כל השיעורים
והטאבים הנסתרים נפתחים, הפקדים נעלמים, וה-hero הופך לעמוד שער.
הגופנים מוטמעים ב-`dist/standalone`, כך שה-PDF לא תלוי ברשת.

## דיפלוי

Netlify מגיש את תיקיית השורש כמו שהיא. חיבור הריפו מספיק — אין פקודת בנייה.
אין צורך בבנייה ידנית לפני push — ה-Action בונה ומקמט את התוצרים, ו-Netlify מעלה מהקומיט שלו.
